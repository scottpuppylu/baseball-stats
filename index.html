一、慢壘特化核心指標：好球帶紀律指數 (Softball Discipline Index, SDI)

【定義】專為慢速壘球運動特性研發之淨好球帶控制指標，用於五維能力雷達圖中取代失真的純四壞率（BB%）。

【計算公式】SDI = (BB - 1.5 × K) / PA

【代表意義與實戰解讀】慢壘具備「好球帶廣、球速慢、開局多為 1 好 1 壞」之特性，強打者以積極攻擊好球為主，四壞保送天然偏少（全隊 BB% 僅 12%）；相對地，在慢壘吞 K 代價極高（全隊 K% 僅 6.5%），通常代表追打惡劣壞球。公式給予三振 1.5 倍懲罰權重，破除「不保送就等於不會選球」的盲點，能真實回饋積極出棒且從不吞 K 的強打者。

二、賽伯計量進階指標 (Sabermetrics)

加權得分創造 (wRC+, Weighted Runs Created Plus)

定義：以全隊平均值 100 為基準的綜合進攻效率標準化指數。

公式：wRC+ = (OPS / Team_OPS) × 100

意義：綜合考量上壘品質與長打推進，排除場地與賽制偏差，是公認最客觀的個人全能進攻身價標準。

加權上壘率 (wOBA, Weighted On-Base Average)

定義：依據賽伯計量得分期望值（Run Expectancy）賦予各進攻事件精確線性權重之上壘指標。

公式：wOBA = (0.69×BB + 0.89×1H + 1.27×2H + 1.62×3H + 2.10×HR) / PA

意義：修正傳統 OBP 忽略長打深度、以及 SLG 線性疊加壘包的瑕疵，精確衡量每打席對團隊得分的實際邊際價值。

預估創造得分 (RC, Runs Created)

定義：由棒球統計之父 Bill James 發明，用於估算打者累計為球隊製造的實體得分數量。

公式：RC = (H + BB) × TB / (AB + BB)

意義：將「上壘因子（H+BB）」乘上「壘包推進因子（TB）」，直觀評估球員在該時間區間內總共為球隊換取了多少實體分數。

純長打率 (ISO, Isolated Power)

定義：過濾一壘安打水分，純粹衡量擊出長打（二壘打以上）的淨長打威力。

公式：ISO = SLG - AVG = (2H + 2×3H + 3×HR) / AB

意義：區分短程巧打型（ISO < .150）與重砲長打型（ISO > .300）的決定性指標。

場內安打率 (BABIP, Batting Average on Balls in Play)

定義：擊球員將球擊入場內（排除三振與全壘打）形成安打的機率。

公式：BABIP = (H - HR) / (AB - K - HR + SF)

意義：慢壘防守站位深且無觸殺時差，BABIP 具體反映擊球落點穿透防線的品質、擊球初速與運氣成份。

次級打擊率 (SecA, Secondary Average)

定義：不依賴擊出安打，純粹衡量打者透過「額外長打」與「保送」獲取壘包的純粹產能。

公式：SecA = (TB - H + BB) / AB

意義：評估打者在安打以外能對投手造成多大壓迫，SecA 愈高代表長打破壞力與選球耐性愈強。

標準化攻擊指數 (OPS+)

定義：將球員個人 OPS 相較於全隊平均 OPS 進行正規化所得的百分比指數。

公式：OPS+ = (OPS / Team_OPS) × 100

意義：數值以 100 為中位數基準；OPS+ 達 135 代表其綜合攻擊破壞力優於全隊平均 35%，低於 100 則低於隊均。

三、好球帶辨識與擊球控制指標

擊球掌握率 (Contact%)

定義：打者在打數中成功將球擊出（未吞下三振）的機率。

公式：Contact% = (AB - K) / AB

意義：衡量打者的球眼穩定度與揮空迴避能力。慢壘防守破綻多，擊出球即能對守備施加失誤壓力。

保送三振比 (BB/K)

定義：打者每吞下一次三振，所能換取之四壞保送次數。

公式：BB/K = BB / K (若 K=0 則計為 BB 總數)

意義：經典選球控制比例。BB/K 大於 1.0 代表選球正向產出多於無效揮空；大於 2.0 屬頂級好球帶掌舵者。

四壞保送率 (BB%)

定義：平均每打席選到四壞保送的機率。

公式：BB% = BB / PA

意義：衡量耐心辨識壞球的能力。慢壘好球率高，BB% 超過 15% 即屬保送機器。

三振率 (K%)

定義：平均每打席吞下三振出局的機率。

公式：K% = K / PA

意義：無效打席產生率，慢壘 K% 理論上應壓制在 5% 以下，K% 過高代表追打兩好球後大壞球嚴重。

四、經典打擊三圍與綜合產能

打擊率 (AVG, Batting Average)

公式：AVG = H / AB

意義：每打數擊出安打的機率，反映擊球穿透防守的最基本頻率。慢壘隊均水準約在 .500 上下。

上壘率 (OBP, On-Base Percentage)

公式：OBP = (H + BB) / (AB + BB + SF)

意義：衡量打者站上打擊區「避免製造出局數」的機率，為攻勢串連之最關鍵基準。

長打率 (SLG, Slugging Percentage)

公式：SLG = (1H + 2×2H + 3×3H + 4×HR) / AB = TB / AB

意義：打者平均每打數所能推進的總壘包數，量化長打破壞力。

整體攻擊指數 (OPS, On-base Plus Slugging)

公式：OPS = OBP + SLG

意義：結合上壘與長打的經典指標。慢壘中 OPS 達 1.200 即屬優異，超過 1.500 屬頂級重砲打者。

六、多變量交叉比對與統計工具

百分位排名 (PR 值, Percentile Rank)

定義：將全隊不同單位的數值透過 Min-Max 最小-最大標準化映射至 0–100 區間。

公式：PR = ((X - Min) / (Max - Min)) × 100

意義：用於五維能力雷達圖，直觀呈現選手在隊內的相對位階，PR 90 代表該指標優於全隊 90% 選手。

皮爾森積差相關係數 (Pearson Correlation, r)

定義：衡量兩個連續變量（如 X 軸上壘率與 Y 軸 wRC+）之間線性關聯強弱的統計量數。

公式：r = Σ(X - X̄)(Y - Ȳ) / (√Σ(X - X̄)² √Σ(Y - Ȳ)²)

意義：介於 -1.0 至 +1.0 之間。|r| > 0.7 為高度相關，|r| 介於 0.4–0.7 為中度相關，輔助球隊驗證打擊指標與得分產能的真實連動性。
