一、慢速壘球專屬特化規程與特有指標

慢壘好球帶紀律指數 2.0 (SDI 2.0) Softball Discipline Index 2.0

公式：SDI 2.0 = (BB - 1.0×界外K - 2.0×揮空K) / PA

說明：慢壘革命性好球帶模型！過去一律以 1.5 倍懲罰所有三振，但慢壘實戰中，打者在兩好球後的『界外三振 (界外K)』多為保護好球帶或纏鬥出棒，其擊球品質與對球路之辨識遠高於遭到投手愚弄之『揮空/站立三振 (-2.0x)』。SDI 2.0 給予兩者精確權重分流，更真實回饋高纏鬥力與零揮空的頂尖打者！

計時賽排棒模型 (Timed-Game Batting Order) Markov + Clock

核心原則：不套用固定的棒次角色，而是計算每種排法在 90 分鐘計時賽中的預期得分，選出最高者。

說明：The Book 指出最強的打者應放在 1、2、4 棒，因為前段打席較多；但最佳排法取決於比賽環境。模型逐打席計算出局數與壘上狀態，並依比賽時鐘決定能打幾局（時間到不開新局），再搜尋預期得分最高的棒次。本隊上壘率很高，長打者排在高上壘率打者之後時常更有利，因此最強打者不一定在第 2 棒；前段棒次之間的差距通常很小，可用「鎖定棒次」依教練判斷調整。

界外三振規程 (Foul Strikeout, 界外K) Slowpitch Rule

規則：兩好球後擊出任何界外球即判出局

說明：慢速壘球特有官方規則。打者在兩好球後（含開局 1 好 1 壞之兩好球情況），若擊出界外球無法形成界內，主審立即裁定打者出局，紀錄上計為 1 次三振（K）、1 打數（AB）與 1 打席（PA）。

慢壘 10 人守備編制 (P, C, 1B, 2B, 3B, SS, LF, SF, RC, RF) Fielding Roster

守位：投捕內野 6 人 + 外野 4 人（左外 LF、自由/左中 SF、右中 RC、右外 RF）

說明：慢壘擊球初速快且飛行距離遠，正規慢壘設有 4 位外野手。其中 SF（自由手/左中外野）通常由運動能力最強、覆蓋範圍最廣之選手擔綱，負責二游中線後方至深遠外野的大面積防區。

慢壘指定打擊 (DH) 11 棒打線特化規程 11-Batter Lineup

編制：10 位守備員全打 (含投手 P) + 1 位純打擊 DH = 11 棒打線

說明：慢速壘球大專院校與系壘聯盟特化規程。實施 DH 制時，投手 (P) 依然必須親自打擊，打線擴編為 11 棒。被指派為 DH 之棒次專職打擊、免除守備體力消耗，極大化打線重砲清壘產能。

跑壘者出局 (Runner Out) Baserunning Out

型態：壘上跑者遭觸殺、刺殺、牽制出局、離壘過大遭捕手回傳刺殺、或跑壘妨礙守備

說明：出局數直接增加 1 點（+1 Out），並清除壘上遭出局之跑壘員。此時正在打擊區的打者打席並未結束，維持原球數與棒次繼續打擊，解決出局數與打席數脫節之記分盲點。

二、進階賽伯計量高階指標 (Advanced Sabermetrics)

加權得分創造 (wRC+) Weighted Runs Created+

公式：wRC+ = (wOBA / Team_wOBA) × 100

意義：以全隊平均 wOBA 為基準（標準值為 100）的進攻產出指數。大於 100 代表優於全隊均值，是當代公認最客觀衡量打者真實進攻身價的黃金標準。

加權上壘率 (wOBA) Weighted On-Base Average

公式：wOBA = (0.69×BB + 0.89×1H + 1.27×2H + 1.62×3H + 2.10×HR) / PA

意義：依據賽伯計量得分期望值賦予每個進攻事件精確線性權重，破除「將一安與全壘打視為同等上壘」之傳統盲點。

標準化攻擊指數 (OPS+) OPS Plus

公式：OPS+ = (OPS / Team_OPS) × 100

意義：個人 OPS 相較於全隊平均的正規化百分比指數，100 為全隊平均線，能直觀評估相較於同隊隊友之攻擊優勢比例。

預估創造得分 (RC) Runs Created

公式：RC = (H + BB) × TB / (AB + BB)

意義：棒球統計之父 Bill James 經典模型。將「上壘因子 (H+BB)」乘上「壘包推進因子 (TB)」，量化評估該打者為球隊換取的實體總分數。

每27出局預估得分 (RC/27) Runs Created per 27 Outs

公式：RC/27 = (RC × 27) / (AB - H + SF)

意義：賽伯計量衡量個人單兵破壞力的最高殿堂指標！假設整支球隊 9 個棒次全由該打者一人包辦，打滿正規 9 局（27 個出局數）時，球隊預期能攻下的總分數。慢壘中大於 15.0 分即屬超強進攻重砲！

純長打率 (ISO) Isolated Power

公式：ISO = SLG - AVG

意義：完全過濾短程一壘安打的水分，純粹衡量擊出長打（二安、三安、全壘打）的淨長打破壞威力。慢壘高於 .250 屬頂級長打砲手。

場內安打率 (BABIP) Batting Average on Balls In Play

公式：BABIP = (H - HR) / (AB - K - HR + SF)

意義：擊球員將球打入場內後形成安打的機率，反映擊球初速、落點穿透防線能力與跑壘速度。

次級打擊率 (SecA) Secondary Average

公式：SecA = (TB - H + BB) / AB

意義：評估打者「除了敲出一壘安打之外」藉由額外壘包推進（長打）與四壞選球所產生的獨立破壞產能，慢壘重砲指標。

預期打擊率 (xBA) 與 運氣因子 Expected Batting Average

公式：xBA = Σ(擊球型態期望值) / AB | Luck = AVG - xBA

意義：MLB Statcast 旗艦指標。根據擊球型態 (平飛 LD=0.68, 滾地 GB=0.28, 高飛 FB=0.38, 沖天炮 PU=0.02) 賦予客觀物理期望值，評估打者擊球品質。若 AVG > xBA 代表運氣極佳；若 AVG < xBA 代表強勁擊球運氣差被沒收。

Statcast 擊球型態分佈 (LD% / GB% / FB% / PU%) Batted Ball Profile

定義：場內擊球 (BIP) 中平飛 (LD)、滾地 (GB)、高飛 (FB) 與無效內野高飛 (PU) 的比例。

意義：平飛球 (LD%) 是慢壘得分的第一推動力；高飛球 (FB%) 是長打來源但過高容易被 4 位外野手接殺；內野高飛 (PU%) 則為幾乎 100% 出局之無效揮棒。

三、傳統打擊三圍與基礎攻守累積數據

打擊率 (AVG, Batting Average)

H / AB

每打數擊出安打之頻率。慢速壘球中隊均水準約在 .500 上下。

上壘率 (OBP, On-Base Percentage)

(H + BB) / (AB + BB + SF)

打者站上打擊區「未製造出局數」之機率，慢壘排棒首要依據。

長打率 (SLG, Slugging Percentage)

TB / AB

平均每打數所推進之壘包數（壘打數 TB = 1H + 2×2H + 3×3H + 4×HR）。

整體攻擊指數 (OPS)

OBP + SLG

綜合衡量上壘穩定度與長打威脅之核心指標。慢壘中大於 1.200 即屬優異。

打席 (PA) 與 打數 (AB)

PA = AB + BB + SF | AB = PA - BB - SF

完成打擊輪次為 PA；扣除不計打數之保送 (BB) 與高飛犧牲打 (SF) 後為 AB。

安打 (H) 與 長打 (XBH)

H = 1H+2H+3H+HR | XBH = 2H+3H+HR

全場擊出安打之總和，與形成長程破壞之二安、三安與全壘打總數。

打點 (RBI) 與 得分 (R)

Runs Batted In / Runs Scored

打擊送回隊友產生之實質分數 (RBI)；跑壘者踩過本壘板之得分數 (R)。

四壞 (BB) 與 三振 (K)

Base on Balls / Strikeouts

四壞保送獲取一壘壘包；三振包含揮空吞K、站著不動被三振與慢壘界外K。

高飛犧牲打 (SF) 與 雙殺打 (DP)

Sacrifice Fly / Double Play

外野高飛球被接殺但護送三壘跑者回本壘得分 (SF)；擊出滾地球形成雙殺 (DP)。

四、擊球掌握度、控制紀律與噴流落點指標

擊球掌握率 (Contact%)

(AB - K) / AB

打者出棒擊入球場、避免吞下三振之機率。慢壘優秀打者應維持在 90% 以上。

四壞率 (BB%) 與 三振率 (K%)

BB/PA 與 K/PA

平均每打席獲得保送之比率，與每打席吞K之比率。慢壘中 K% 應盡量壓低於 5% 內。

保送三振比 (BB/K)

BB / K

選球好球帶耐性比例。大於 1.0 代表選球正向產出大於負向揮空吞K。

滾飛比 (GO / AO)

滾地球出局 / 飛球出局

衡量打者出棒軌跡為下砍滾地還是仰角高飛球。數值過低通常伴隨較高飛球接殺率。

噴流落點方向 (Pull% / Center% / Oppo%)

拉打率 (左半邊) / 中線率 (中路) / 推打率 (右半邊)

將球場三等分：左半邊三游外野為 Pull%，二游自由中外野為 Center%，一二壘右外野為 Oppo%。反映廣角推拉打能力與對手佈陣破綻。

五維能力 PR 百分位 (PR 0–100)

Percentile Rank 標準化 0–100

以全隊球員常模為樣本：擊球率 (AVG)、長打破壞 (ISO)、好球帶紀律 (SDI)、擊球掌握 (1-K%)、進攻產出 (wRC+)，90 以上為全隊頂尖 (S級)。

五、慢速壘球投手賽伯計量進階指標 (Slowpitch Pitching Sabermetrics)

💡 慢壘科學核心原理：為什麼傳統棒球 ERA 在慢速壘球完全失效？
慢速高拋壘球投出的球速僅 30~50 km/h，且強制拋物線弧度，聯盟打者平均打擊率高達 .500~.600，被擊出安打是物理常態。傳統防禦率 (ERA) 嚴重受到守備員範圍、失誤與外野漏接之劇烈污染，完全無法反映投手真實水準。慢壘投手的第一天職是「極端壓制四壞保送」與「製造弱化出局」！
慢壘獨立防禦率 (sFIP) Slowpitch FIP

公式：sFIP = (3.0×BB - 2.0×K_swing - 1.5×K_foul) / IP + 4.5

說明：完全剝離守備隊友與安打運氣干擾，只評估投手個人完全掌控的事件：保送 (BB) 施加最大懲罰 (+3.0)，揮空三振給予強力獎勵 (-2.0)，兩好球界外誘殺給予顯著獎勵 (-1.5)。慢壘中低於 3.50 即屬超級神級王牌！

好球帶好投率 (ZCR) Zone Control Rate

公式：ZCR = 1 - (BB / TBF) = (TBF - BB) / TBF

說明：慢壘投手的核心天職！衡量面對打者時，能有效將球送進好球板或迫使打者出棒、避免奉送免費保送的機率。慢壘送保送等同於自爆大局，頂尖投手 ZCR 必須維持在 93% 以上。

兩好球界外K誘陷率 (FKR) Foul-K Ratio

公式：FKR = K_foul / (K_swing + K_foul)

說明：慢速壘球專屬魔球戰術！慢壘官方規則規定兩好球後擊出界外球即判出局。頂級投手深諳心理戰，在兩好球後專門投出深遠外角或極高下墜弧度，誘騙打者出棒削成界外球強行抓出局！

場內擊球轉出局率 (BIP Out%) BIP Out Conversion

公式：BIP Out% = (GO + FO + DP) / (GO + FO + DP + Hits)

說明：慢壘被打進場內是必然。該指標衡量被打入場內的球有多少比例能被隊友抓下出局，反映了投手投球球質是否具有優異的「弱化擊球」效果（多形成軟弱滾地或無害沖天炮）。

每7局四壞保送數 (BB/7) Walks per 7 Innings

公式：BB/7 = (BB × 21) / Outs

說明：慢速壘球正規賽事為 7 局制（21 個出局數）。BB/7 能精確衡量投滿整場 7 局預期會送出幾次保送。低於 2.0 次為絕對王牌水準。

投手滾飛出局比 (GO/AO) Ground-to-Air Ratio

公式：GO/AO = GO / FO

說明：區分投手出局風格。大於 1.5 為滾地球重下沉型（內野雙殺多、長打威脅小）；小於 0.8 為高拋飛球型（考驗外野 4 人守備覆蓋）。
