# 現行功能基準與響應式改版保留清單

盤點日期：2026-10-04。程式基準：`903cf9777924e28f6409c5293cbf7f899e841a39`。

本文件依 `index.html` 的頁面、事件處理、計算、資料讀寫與頁面連動整理。此次只建立文件，未修改 UI、數據公式或業務規則。程式閱讀不等於所有操作已完成瀏覽器實測；下列驗收項目是後續改版必須執行的檢查。

## 1. 改版約束

- 現有功能作為保留基準：調整布局與操作入口，不因手機空間不足刪掉指標、圖表、篩選或編輯功能。
- 隊內比較與推估指標沿用既有算法；不得在 UI 改版時擅自替換成外部聯盟標準。
- 手機、平板與桌機應共用資料、計算與操作結果；差異在布局、資訊展開及觸控方式。
- 所有隱藏或收合的功能必須保留可發現的入口，且能完成原本的流程。
- 日期、球員、比較對象、圖表軸線、排棒、比賽進度與編輯狀態，不應因版面切換或螢幕旋轉而意外重置。
- 本機保存、同步中、雲端成功及同步失敗必須能辨識，不把本機保存當作雲端完成。

九個主頁面：總覽、個人、排行榜、分析、比較、排棒、場記、投手、指標說明。場記另有即時記分、賽事覆盤、落點分析三個子頁面。

| 功能 | 現行行為與保留要求 |
| --- | --- |
| 日期範圍 | 起日、迄日、全部及 114／115／116 年度快捷範圍；日誌翻頁隨日期變更回第一頁。 |
| 特定球員排除 | 「簡承均」開關影響總覽、個人、排行榜及分析的打擊聚合；比較與排棒仍使用完整聚合。不可誤改成全站排除。 |
| 更新與狀態 | 手動更新；GitHub 讀取、靜態 JSON 備援及本機快取；狀態徽章與手機狀態點提示。 |

## 3. 各主頁功能

### 總覽

- 全隊 AVG、OPS、PA 與 AVG／HR／wRC+ 領先者摘要；球員入口可跳至個人頁。
- 完整球員統計表；日期篩選的逐筆日誌，每頁 15 筆、上一頁／下一頁。
- 手動補登日期、賽事標籤、背號、PA、BB、SF、各類安打、HR、K；預覽 AB 與 H。
- 不存在的背號可引導註冊隊員；註冊檢查姓名及背號重複。
- 刪除一般日誌，或連動刪除由賽事產生的整場紀錄及日誌；保留確認與同步結果提示。

### 個人

- 球員選擇、背號、基本累計、傳統三圍、OPS／OPS+、wRC+／wOBA、SDI 與 K 分類、RC／RC27／出局數。
- 頭像上傳、清除、裁切；滑鼠／觸控拖曳、縮放、90 度旋轉、重置及保存。
- 個人標籤新增／刪除，最多三個，每個最多八字且避免重複。
- 相對能力雷達、安打組成、擊球型態與隊均比較、方向分布、實際與預期指標比較。
- 個人落點：全部／安打／長打／出局、每球詳細資訊、樣本數、方向、GO/AO 與提示。
- 診斷展開／收合：目前球員、全隊、急迫改善、長打缺口及擊球掌握度名單；優勢、問題與建議。

### 排行榜

- 最低 PA 門檻、前三名與完整排行；點選球員跳至個人頁。
- 指標選擇涵蓋 wRC+、OPS、OPS+、wOBA、RC、RC27、AVG、OBP、SLG、ISO、BABIP、SecA、xBA、xwOBA、LD%、Pull%、Oppo%、SDI、Contact%、BB%、K%、BB/K、H、HR、BB、PA。
- K% 採低者優先；保留各指標說明與公式，不用單一綜合分數取代。

### 分析

- 五種象限：OBP／SLG、LD%／xBA、Contact%／SDI、wRC+／ISO、xBA／BABIP；隊均分界與球員跳轉。
- 自訂氣泡圖、散點圖、雙軸柱線圖、柱狀圖；X／Y／Z 指標選擇及相關係數。
- xBA／BABIP 回歸比較圖。
- 全隊／個人空間分析，結果篩選、落點細節、方向、LD% 與防守站位建議。

### 雙人比較

- 左右球員選擇、照片、標籤、樣本量、三圍與核心能力。
- 31 項比較：PA、AB、H、HR、AVG、OBP、SLG、OPS、OPS+、wOBA、wRC+、RC、RC27、ISO、BABIP、SDI、Contact%、LD%、GB%、FB%、PU%、Pull%、Center%、Oppo%、xBA、xSLG、xwOBA、Luck、BB%、K%、BB/K。
- 優勢／同分標記；K% 與 PU% 等反向指標保留判斷方向。
- 疊合雷達、雙人落點、方向與擊球戰術比較。

### 排棒

- 10 棒／啟用 DH 的 11 棒切換；投手仍打擊，DH 不是直接取代投手打席。
- 出席選擇、全選、歷史 PA 門檻快速選取、清除；歷史 PA 與目前日期範圍 PA 用途不同。
- 十個守位的五順位教練設定、保存與同步；推薦打線結合出席、守位配對、投手資格及打擊能力。
- 推薦名單、棒次理由、人數不足提示、套用至自訂、重置。
- 自訂每一棒、DH 棒次、重複選人提示；正式隊員排棒與賽事支援選手是不同流程。
- 自訂打線逐棒能力與適性、八項整體評估、缺口診斷、OPS／wRC+ 威脅圖。

### 投手

- 日期範圍內的防守事件歸屬到當時投手；舊紀錄有相容推估，支援選手不納入正式投手分析。
- 投手完整表格與選取：局數、面對人次、保送、三振分類、滾飛出局、雙殺、跑者出局、被安打與失分等。
- ZCR、sFIP、FKR、BIP Out%、BB7、R7、GO/AO、sWHIP、K% 等隊內指標。
- 四個重點能力卡、出局結構、五軸雷達、投球型態與戰術建議。

### 指標說明

- 保留傳統、進階、擊球品質、紀律、排棒及慢壘投手指標的定義、公式、讀法與情境說明。
- 手機收合後仍須能找到對應指標；不要只剩縮寫而沒有解釋入口。

## 4. 場記完整流程

### 賽前與進行中

- 建立比賽：日期、對手、標籤、先攻／後攻、10／11 棒、打線匯入或逐棒設定、支援選手。
- 保存先發打線快照與現行打線；替補保留棒次、時間、局數及上下半局。
- 比分板至少七局並支援延長；我方／對方順序、R／H、局分與局安打；對方總分可調整。
- 出局提示與壘包手動切換；目前與下一位打者、當場成績、跳下一棒及替補。
- 球場點選落點、守位快捷選擇、四種飛行型態、打擊結果、RBI 與得分各自設定。
- 結果包括一至三壘安打、HR、GO、FO、LO、SF、E、FC、DP、界外 K；另有快速 K、BB 與跑者出局。
- 跑者出局操作保持目前打者，不直接結束打席；三出局提示後手動換局。
- 打擊與守備逐筆紀錄及刪除；刪除與計分、出局、棒次的連動須單獨驗收。
- 防守模式：GO、FO、K、界外 K、DP、跑者出局、BB、HIT、對方得分；保留每筆投手身份。
- 換投可從場上、場下或支援選手選擇；場下換投可指定替換某棒，或僅換投不替換打線。
- 手動換局、手動同步目前比賽、完賽與放棄；保留本機比賽恢復及離頁提示。

### 覆盤與編輯

- 選擇歷史賽事；比分、局分、先發／替補順序、個人 box score、全隊合計、逐打席內容、落點及得分效率提示。
- 本場登入全隊日誌、撤銷登入、刪除整場及相應日誌。
- 編輯日期、對手、標籤、預設投手與雙方總分。
- 各進攻半局：新增／刪除打席，修改打者、結果、型態、守位、RBI、得分。
- 各防守半局：新增／刪除事件，修改投手、事件種類、增加出局數、失分及備註。
- 保存後重算局分／局安打並連動全隊日誌、個人及投手數據；保存失敗須明確呈現。
- 現版新增／刪除會重繪表單，直接修改記憶體物件；「取消」不代表有完整交易式回滾。改版不得先假設已有未保存草稿隔離。

### 場記落點工作室

- 全隊／球員選擇、全部／安打／長打／出局篩選、每球資訊、樣本數、方向比例、滾飛比與提示。
- 落點細節目前部分依賴 hover 或 SVG title；觸控版需要可點選的等價入口。

## 5. 資料連動與範圍

主要鏈路：場記事件 → 歷史賽事 → 自動產生正式隊員日誌 → 日期篩選聚合 → 總覽／個人／排行／分析／比較／排棒。投手分析另從防守事件取數；落點圖主要從賽事打席取數。頭像、標籤、守位與支援名單是獨立資料。

- 一般數值指標依日期篩選日誌；個人、比較、分析與場記的部分落點圖直接遍歷全部歷史賽事，現版並非所有圖都套用日期範圍。（2026/10/10 起四個彙總落點圖皆依日期範圍篩選，單場覆盤除外。）
- 出席初始化使用歷史 PA；排棒能力又使用篩選後聚合，不能誤把兩者合併。
- 自動日誌重建保留手動日誌與隊員註冊，排除模擬賽事與支援選手。
- 自動重建與覆盤單場登入存在不同的聚合路徑；UI 改版先保持資料路徑，避免順帶變更計算。
- 同步是不同 JSON 檔案的多次寫入，並非原子交易；任一失敗時不可顯示全數完成。

## 6. 後續響應式驗收

| 裝置 | 顯示與操作驗收 |
| --- | --- |
| 手機直向 | 所有九頁及場記三子頁可達；表格可看所有欄位，必要時欄組切換與局部橫滑；姓名／棒次可定位；觸控落點細節；表單、選單與彈窗不超出畫面；同步與錯誤可見。 |

每種裝置都要覆核：日期／球員切換、排行榜排序、各圖表設定、照片與標籤、守位保存、出席與 DH、自訂排棒、支援名單、完整先攻及後攻場記、替補與兩種換投、刪除逐筆、換局、恢復、覆盤增刪改、完賽、同步失敗及重試。流程測試應使用隔離資料與模擬寫入，避免改動正式隊內紀錄。

## 7. 程式閱讀後仍需實測的既有邊界

這些項目不是本次 UI 變更，也尚未修正；後續驗收需要區分既有行為與改版引入的差異。

- 跑者出局寫成 `OUT`，部分統計排除判斷則檢查 `RUNNER_OUT` 或 `isRunnerOut`，需確認不額外增加打席。（2026/10/10 已確認會多算打席並修正，見 UI_QA.md。）
- 投手下拉選單與表格點選採不同事件入口，需確認下拉確實更新目前投手。
- 完賽同步失敗雖保留本機物件，但賽事狀態已切為 finished；需驗證重繪後的重試入口仍可使用。現有同步回饋模擬測試不證明此畫面流程已通過。
- 覆盤增刪重繪、取消、結果／守位修改對座標及其他衍生欄位的影響，需以隔離資料驗收。
