# App 化改版（2026/10/26）

由 `ui-app.js`（主頁、版本紀錄頁、頂部工具列、返回鍵、圖表觸控）、`ui-comfort.js`（網站地圖與分頁群組）與 `ui-theme.css`「APP SHELL」區塊組成。所有原本的按鈕、ID 與處理函式不變，只是被移動或分組。

## 網站地圖

| 群組 | 頁面（分段切換） |
| --- | --- |
| 主頁 | 開啟網站的第一頁 |
| 球隊數據 | 總覽・分析・投手・紀錄 |
| 球員 | 檔案・排行・比較・健康 |
| 比賽 | 打線・場記 |
| 參考（在「更多」裡） | 指標說明・版本紀錄 |

- **手機**：底部分頁列五格：主頁／數據／球員／比賽／更多。每格記得上次停留的子頁（像 App 的分頁）；「更多」列出所有頁面。被選中的分頁有一塊玻璃「滑塊」以彈性動畫滑過去，圖示保留各自顏色（數據藍、球員綠、比賽金）。
- **平板**：頁面仍收在側邊抽屜（☰），不顯示手機分頁列；同群組的頁面用標題下方的分段控制切換。
- **電腦**：左側玻璃側欄列出全部頁面（隊徽＋隊名按鈕回主頁）；不顯示分段控制。
- 返回鍵／返回手勢在頁面之間返回（不是直接離開網站）。點左上角隊徽回到主頁。

## 頂部工具列

原本兩排的頁首（日期輸入、四顆按鈕、雲端狀態、版本）改為一條細玻璃工具列，所有工具收進「工具與篩選」面板（日期範圍、即時重整、守位設定、簡承均切換、匯出 CSV、雲端狀態、版本、系統建構）。

- 手機：隊徽・（捲動後出現的）頁名・雲端燈・工具。平板：☰・隊徽・頁名・日期・雲端燈・工具。電腦：頁名・日期・雲端燈・工具。
- 頁名採 iOS 大標題做法：頁面的大標題捲出畫面後，工具列才淡入顯示頁名。主頁時工具列透明浮在主視覺上，捲動後變為玻璃。
- 本頁段落籤（手機）停靠在工具列下方。

## 主頁

像 Apple 首頁一樣完全展開：滿版主視覺（軌道上的地球邊緣，`assets/bg-orbit*.webp`）＋隊名、一句近況、一顆主要按鈕（開始／繼續比賽場記）與「安排今日打線 ›」，底部是全隊打擊率／上壘率／OPS／打席。往下是全寬區塊：近期比賽（手機可左右滑的卡片，點開覆盤）、區間焦點（打擊王、全壘打王、進攻破壞王，點開個人檔案）、所有功能（四大群組卡片）、目前版本與更新內容連結。主頁隱藏時不保留 HTML（頁面大小預算）。

## 玻璃：液態玻璃（整面透鏡＋淺景深）

- 所有玻璃面（頂部工具列、手機分頁列、工具面板、分段控制、段落籤列、側欄／抽屜、圖表小卡）是**整面透鏡**：`ui-theme.js` 依每個元素的實際尺寸與圓角產生位移圖，整面輕微放大凸起、邊緣彎折最強，紅綠藍位移量略不同形成細微色散；做成 SVG 濾鏡當 `backdrop-filter`，元素出現或改變大小時重建。`ui-app.js` 以 `window.flRefract()` 登記它建立的元件。
- 與背景的區隔靠**淺景深**而不是毛玻璃：透鏡內是乾淨的失焦模糊（保留顏色與對比、不加白霧），強度依元件設定（`--fl-lens-defocus`）：手機分頁列最透（2.2px、背後只稍微變暗），工具列與分段控制 3.5px，側欄 6px，工具面板最隔離（9px、背後變暗到 55%）；打開工具面板時整個頁面也一起失焦。文字與圖示有柔和陰影，陽光下清楚。
- 玻璃裡不能再包玻璃（瀏覽器只讓內層看到外層），所以工具面板放在頁面層級，打開時定位在工具列下方。
- Safari、Firefox 不支援 SVG 背景濾鏡：同樣透明，改用一般模糊（分頁列 4px、面板 14px）與同樣的變暗；系統「增加對比」或「減少動態效果」時關閉透鏡、改為不透明底。
- 按鈕的語意色保留在文字、圖示與折光邊上。

## 頁面太空背景（2026/10/26）

除了比賽場記（保持素色，不干擾即時記分），每頁一個太空主題：主頁地球邊緣、全隊總覽銀河、數據分析星雲、投手分析火星、生涯紀錄土星、排行榜月球與地出、雙人比較雙星、健康極光、打線木星、指標說明螺旋星系、版本紀錄彗星、球員檔案地球與擊球軌跡。全部由 `scripts/build-backgrounds.py` 程式產生（橫式 2560×1440、直式 1290×2400；`python scripts/build-backgrounds.py saturn` 可單獨重建），沒有第三方圖片。

- 背景是固定在畫面後方的一層（不用 `background-attachment: fixed`，iPhone 才正常），換頁時淡入；直式螢幕（手機、直式平板）用直式構圖；上面再蓋一層漸層變暗以利閱讀。
- 內容區塊是高透明液態玻璃：約 30% 底色，靠強烈的淺景深失焦（電腦 22px、觸控 16px）與背景變暗（約 65%）維持閱讀，邊緣折光，滑鼠裝置上面積適中的區塊另有即時折射。區塊內的小卡是淡色液態玻璃（漸層、高光邊、內緣陰影，不另做模糊）。
- 行星、月球與地球以球面貼圖繪製：3D 雜訊紋理貼在球面上（越靠近邊緣自然壓縮）、依光線方向的地形起伏光影、柔和晨昏線、氣態巨行星邊緣變暗、地球與火星的大氣散射光暈；土星環有細環紋、卡西尼縫、恩克縫與行星投影。
- 頁面背景不預先下載到離線快取（離線時顯示深色底）。

## 效能（iPhone 13／Galaxy S21）

- **不在瀏覽器裡編譯 Tailwind**：`vendor/tailwind-site.css` 由 `node scripts/build-tailwind.cjs` 預先產生（把頁面與程式裡所有 class 交給同版 Tailwind 3.4.17 產生 CSS），放在原本 Play 編譯器注入的位置，層疊順序不變。原本的 Play 編譯器會監看每個 DOM 變化並重新產生樣式，是手機捲動時最主要的運算來源。新增或修改 class 後要重新執行；`tests/tailwind-static.test.cjs` 會檢查。
- 捲動時不改動 DOM（頂部頁名只在文字不同時才寫入，捲動處理以 requestAnimationFrame 合併）。
- 玻璃內的小按鈕不再各自做背景模糊；觸控裝置上內容區塊的失焦較輕（16px）；內容區塊的即時折射只在滑鼠裝置上啟用，手機保留分頁列與工具列的折射。
- 換頁、展開等動畫只動透明度與位移（不動 blur 濾鏡）；觸控裝置的圖表動畫縮短為 0.42 秒。
- 量測方式：手機視窗、CPU 降速 4 倍、真實 GPU，捲動各頁 3 秒記錄每一幀。改版前分析／檔案／紀錄頁每 3 秒有 41–47 次超過 50ms 的卡頓；改版後 0 次、第 95 百分位單幀 5.7ms。

## 按壓回饋

所有可以按的元素（按鈕、帶 onclick 的卡片與列、cursor-pointer、summary、select、主頁卡片、名冊卡片）按下時有光暈與縮放（大卡片 97.5%、表格列改為亮度提示），放開彈性回彈；電腦上滑過卡片微微浮起。系統「減少動態效果」時關閉。

## 載入不閃舊畫面

`boot.js` 是頁面第一支程式：載入期間只顯示太空背景與隊徽，等 `ui-app.js` 把整個介面整理好才顯示（最多 6 秒保險，避免任何錯誤讓畫面一直不出現）。`tests/ui-app-shell.cjs` 會檢查舊版面被解析時確實藏在啟動畫面後；`tests/ui-joined-cards.cjs` 檢查所有頁面、三種尺寸都沒有「卡片被連成一整條」。

## 圖表觸控

象限圖、Statcast 運氣回歸圖等：滑鼠移上顯示資訊、點擊開啟個人檔案（不變）。觸控裝置上第一次點只顯示該點的提示框與一張小卡（球員名＋「查看檔案 ›」），按卡片才開啟檔案；開卡期間提示框固定不被後續觸控事件清掉。擊球落點圖的點在觸控時也會填入下方的詳細資訊列。

## 字體

改用 Apple 的做法：iPhone／iPad／Mac 使用系統字（SF Pro＋蘋方 PingFang TC），其他裝置使用內附的 Inter＋思源黑體子集。全站一套無襯線字，標題以較粗字重與略收的字距取代原本的明朝體（`TK Mincho` 不再載入）。字型子集未含的少數字（例如部分版本紀錄文字）在 Windows 上會以系統字顯示；Apple 與 Android 裝置不受影響。

# 視覺系統「Flight」（2026/10/25）

外觀與版面層：`ui-theme.css` + `ui-theme.js`，套用於 `<html class="ui-flight">`。不改任何資料、統計公式或按鈕行為；按鈕與頁面元素保留原本 ID 與處理函式（版面調整只「移動」既有元素）。把 `ui-flight` 從 `<html>` 拿掉即恢復舊外觀。

## 風格

- **SpaceX 太空基底**：近黑（不是純黑）的深空畫布，極淡的星點與行星地平線光暈；細線分隔；英文區塊標籤改為寬字距的任務標籤；取消霓虹膠囊、漸層字、發光陰影、閃爍圓點，以及 Tailwind 偏藍的 slate 漸層。
- **Apple 液態玻璃**：側欄、頂部指令列、底部分頁列、抽屜、彈窗、提示列是真正的毛玻璃（`backdrop-filter`，背景內容透出並模糊）；按鈕與卡片有 1px「折光」邊（左上偏冷、右下偏暖）與上緣高光。彩色按鈕保留語意色，但顏色只在文字與邊框。
- **日式字體排印**：
  - 標題：思源宋體（Noto Serif TC，明朝體）600，字距 0.06–0.16em，啟用 `palt` 標點緊排。
  - 內文：思源黑體（Noto Sans TC）400／500／700，字距 0.025em，行高 1.7。
  - 英文與數字：Inter，表格數字等寬對齊（tabular）；中英混排時英數用 Inter、漢字用思源（和歐混植）。
  - 字型檔只含網站用到的 1,333 字（四個字重合計約 830 KB，PWA 會快取以便離線）；新出現的字（例如新球員姓名）自動改用系統字型顯示。

## 手機分頁列的即時折射

- 分頁列只做很輕的霧化（9px），底下捲過的內容清楚透出；圖示與文字加柔和陰影，在任何內容上、太陽下都看得清楚。
- Chrome／Android／Edge：`ui-theme.js` 依分頁列實際尺寸產生「透鏡」位移圖（邊緣最強、中央不變形），做成 SVG 濾鏡當 `backdrop-filter`，內容捲動時邊緣即時彎折，紅綠藍三色位移量略有不同，形成細微色散。位移圖以 blob 網址載入，不增加頁面 HTML。
- Safari（iPhone）與 Firefox 不支援 SVG 背景濾鏡，維持同樣透明的霧面玻璃，不會變成不透明或失去模糊。
- 系統「增加對比」或「減少動態效果」時關閉折射。

## 動態與回饋

- **每個按鈕**：按下縮小到 95.5% 並提亮，從手指位置擴散一圈光（一個共用的覆蓋層以 Web Animations 播放，按完不改動頁面任何元素），放開彈性回彈；Android 輕震 6ms（iOS Safari 不支援網頁震動）；鍵盤 Enter／空白鍵相同。滑鼠移上去時邊緣高光變亮。
- **切換分頁**：新頁面從柔焦淡入（約 0.35 秒），頁面內各區塊依序浮現；被選中的導覽項目、分頁列項目、區塊跳轉籤有彈性「彈一下」。
- **彈窗**：背景淡入，卡片從 94% 彈性放大到定位。**抽屜／更多面板**：彈簧滑入，選單項目依序出現。**展開區塊**（`<details>`、顯示隱藏內容）：柔焦淡入。
- 動畫只用 Web Animations 與 CSS，結束後不留下任何 class、行內樣式或元素；頁面切換只用透明度與模糊，不移動版面，點擊位置不會偏。
- 系統「減少動態效果」開啟時，縮放、光圈與轉場全部關閉。

## 陽光下清晰（不盲目追求最高對比）

主要文字不用純白、背景不用純黑；所有文字色在所有底色上至少 5.8:1（WCAG AA 為 4.5:1）：

| 文字 \ 底 | 頁面 | 卡片 | 輸入框 | 玻璃按鈕 |
| --- | --- | --- | --- | --- |
| 主要 `#e8ebf0` | 16.5 | 15.4 | 16.7 | 14.1 |
| 次要 `#b4bcc8` | 10.3 | 9.6 | 10.4 | 8.8 |
| 第三 `#8e98a6` | 6.7 | 6.3 | 6.8 | 5.8 |
| 數據色（藍／綠／紅／黃／紫／青） | 8.7–12.3 | 8.2–11.6 | 8.8–12.5 | 7.5–10.6 |

玻璃面板的文字一律在不透明度足夠的底上；系統「增加對比」時取消透明、加亮次要文字與邊線。10–11px 小字提高到 11.5–12px。

## 維護注意

- 導覽 `#mainNavigation` 在載入時由 `ui-theme.js` 移到頁首之後（同一個元素），否則頁首的 `backdrop-filter` 會把固定定位的側欄／抽屜困在頁首裡。
- 折光邊是畫在 border-box 的背景，填色層下必須墊不透明底（`--fl-glass-base`），否則邊框顏色會滲進整顆按鈕。
- 頁面 HTML 有 100 萬字元上限檢查（防止 base64 頭像），所以這一層刻意不新增 DOM 文字（側欄英文標語用 CSS `content`）。
- 新增字型字元：改內容後執行 `python scripts/build-fonts.py …` 重新產生子集。

## 2026/10/26 第四輪：反應速度、字體、高透玻璃、場記快捷鍵、賽後成績圖

- **按壓反應**：觸控點擊導覽（底部分頁列、頁面切換列、抽屜選單）先畫出選取狀態，下一格畫面才呼叫換頁（`ui-comfort.js` 的 `soon()`）；滑鼠與程式呼叫維持同步。按壓光暈只動畫 `opacity` 與 `transform`（`#flRipple > span`），並在寫入前先讀版面。
- **版面工作**：`ui-comfort.js` 的整理（表格摺疊、黏性欄、區段列）只處理目前顯示的頁面，忽略按壓／玻璃等暫態 class 的變動，並在畫面畫出後才執行；`phone()` 用 media query，不讀 `innerWidth`；讀寫分批，避免反覆強制排版。
- **折射玻璃**：形變圖以約 2.4 萬取樣點計算、直接寫成 BMP（不經 canvas／PNG 壓縮），由 SVG 濾鏡放大到元件尺寸。
- **量測**：`Event Timing` 於手機視窗、CPU 降速 4 倍：按下到畫面回應約 30～60 ms（原 1～1.5 s）。
- **字體**：標題 `--fl-mincho` = 思源宋體 Black（`vendor/fonts/tk-serif-900.woff2`）；內容 `--fl-font` = Source Serif 4（英數，`serif-latin-*.woff2`）＋ PingFang TC／思源黑體（中文）。Inter 已移除。重新產生：`python scripts/build-fonts.py <NotoSansTC VF | -> <NotoSerifTC VF>`。
- **頁面按鈕（高透玻璃）**：切換列、區段按鈕、頂列圖示按鈕為近乎透明的底＋0.5px 細邊，選取者為略濃的玻璃；不使用高光斑或外發光。
- **場記防守快捷登打**（`.fl-def-pad`）：分「出局」「上壘・失分」兩組大按鈕；寬度 ≥768px 時與守備圖左右並排、上下對齊（`.fl-def-row`），手機放在守備圖上方。場記頁不播放區塊滑入動畫。
- **賽後成績圖**：行星地平線背景（`assets/bg-orbit-portrait.webp`）＋暗色遮罩、透明玻璃面板、宋體標題、襯線數字；開啟前先載入字體與背景（最多等 2.5 秒）。
- **換行**：短按鈕與標籤 `word-break: keep-all`；小篩選鈕與數據卡標籤整段不拆、改為換列；段落 `text-wrap: pretty`、標題 `balance`。

## 2026/10/28：折射回到觸控裝置、首次開頁與按壓動畫

- **折射**：Chromium（Android、Chrome 平板、電腦）全部恢復 SVG 位移折射；Safari／iPhone 不支援 SVG backdrop filter，維持清透模糊。抽屜與工具面板滑入期間以 `--fl-glass-moving`（一般模糊）暫代折射，動畫結束即恢復（`ui-theme.js` 的 `calmGlassWhile`）。
- **首次開頁**：Chromium 上，面板第 2 個以後的 `section` 使用 `content-visibility: auto`（`contain-intrinsic-size: auto 900px`），畫面外不做樣式與排版；場記、打線、健康頁不套用；WebKit 不套用（曾偶發當掉）；列印與 `html.fl-full-layout`（測試量測用）時完整排版。區段跳轉先平滑捲到估計位置，`scrollend` 後校正到實際位置（使用者觸控或捲動則取消校正）。
- **只畫需要的頁面**：資料或篩選改變時只重畫目前頁面，其他頁打開時才重畫；資料沒變回到看過的頁面不重畫；圖表 `upsertChart()` 原地更新（含內嵌外掛的圖表重建）。
- **按壓與轉場**：按鈕、卡片與 Tailwind `.transition` 只轉場 transform、顏色、邊框、透明度；不轉場 box-shadow、filter、backdrop-filter（每格重繪）。大卡片按壓只縮放，不加亮度濾鏡。
- **工具面板**：頂部位置以 ResizeObserver 追蹤頁首高度，開啟時不再強制排版。

## 2026/10/29：指標說明白話化

- **卡片格式**：指標說明 37 張卡片統一為「名稱＋英文名 → 看什麼（一句白話）→ 公式／定義 → 怎麼看（判讀方向與參考值）」。手機收合時只顯示名稱與「看什麼」，點開才顯示公式與判讀。
- **語氣**：避免誇張形容（「革命性」「神級」「魔球」等），只寫數據代表什麼、越高或越低越好、慢壘參考值。
- **與程式一致**：BIP Out% 公式寫成程式實際算法（雙殺算 2 個出局）；xwOBA 註明長打仍照實際結果，只排除部分運氣；xSLG、xwOBA、R/3出局併入既有卡片說明；排行榜補上 Pull%、Oppo% 說明。
- **字型子集**：新增文字前先比對 `vendor/fonts/tk-charset.txt`；沒有原始字型可重建子集時，改用子集內已有的字詞，避免單字退回系統字型。
