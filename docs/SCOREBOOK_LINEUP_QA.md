# 先發打線與即時歐打單

日期：2026-10-18（Asia/Taipei），2026-10-19 更新收合與守備檢視。初版基準：正式網站 `main` 的 `45c4c29`；本次基準 `08817ac`。

## 操作與資料規則

- 開賽前每棒直排一列，顯示頭像、大棒次、球員與守位選單。推薦載入沿用推薦守位，自訂載入依既有守位順位配對；記錄員可再調整。
- 選擇已在打線的球員會交換兩棒的球員；選擇已占用的守位會交換兩棒的守位。重複球員或缺少守位不能開賽。
- 下方守位圖共用噴流圖的 `FIELD_BASE_SVG`，即時標示十個守位的姓名及棒次；DH 顯示在圖下。
- 開賽後比分板下方顯示可收合的歐打單，預設收起；概要持續顯示目前／下次打擊棒次。展開後可捲動，每棒可獨立代打／換人、修改守位；保留原有當前打者的換人入口。收合偏好只存在目前分頁的 sessionStorage，重新整理仍保留，不寫入比賽紀錄。
- 守備時直接顯示「查看目前球場守位」，與歐打單分離；收起歐打單仍可查看。只顯示我方目前守位，點圖不會變動守位、不會改動打擊落點輸入，也不新增敵方落點紀錄。進攻時回到原本可輸入落點的打擊球場。
- 黃色外框追蹤當前棒次；我方守備或已三出局時明確標示「下次打擊」。打席前進、撤銷及重新整理都維持正確棒次；跑者出局不跳棒。
- 代打接替該棒次並沿用守位。換投選單與歐打單的 P 使用同一個登板投手；原本僅登板、不占打序的場下投手模式仍可使用。
- `lineup` / `startingLineup` / `substitutions` 沿用既有格式。新增 `lineupPositions`、`startingPositions`、`positionChanges`；更動不回寫已完成打席或守備事件，不變動先發快照。
- 舊比賽只帶入已知 P、DH，其餘顯示未指定。單純瀏覽不寫入或遷移紀錄；明確修改才新增守位資料。
- 11 棒切成 10 棒仍沿用原系統移除第 11 棒的規則；原 DH 接替被移除的野手守位。若被移除的是投手，保留其僅登板、不占打序的模式。先發快照不變。
